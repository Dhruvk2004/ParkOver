Proposed: free map stack instead of Google Maps

3 Nov 2026

No Google billing account, so the map moves to MapLibre with OpenFreeMap vector tiles and a ParkOver style. Checked with a real render around Chembur: the restyled map looks clean and on-brand, not like default OpenStreetMap.

Map
MapLibre (official maplibre-compose library for Compose) + OpenFreeMap tiles: no key, no billing, no request limit on the public server, but no uptime guarantee.
Distance
Show road distance, not straight line. Measured: Chembur → Phoenix Marketcity is 4.83 km straight but 9.68 km by road (11 min, no traffic). Use OpenRouteService (free: 2,000 routes and 500 matrix calls a day) for road distance, ETA and the route line.
Search
Photon public API (fair use, throttled if heavy) plus searching our own parking list.
Navigation
Directions button hands off to the Google Maps app, which does voice turn-by-turn and live traffic for free.
Lose
Live traffic inside our app and Google's shop and building details.

Parking data needs real sources (next phase)

3 Nov 2026

The current parking list is a hand-made JSON file. Checked the free options for Mumbai:

OpenStreetMap
430 parking places in Mumbai, but only 11% have a name, 4% a capacity, 14% fee info and almost none opening hours. Good for locations only.
BMC open data
MCGM publishes an off-street parking dataset (public lots, BEST depots) as free CSVs. Official, but small and possibly out of date.
Real apps
SpotHero-style apps get most of their inventory and live availability through direct partnerships with garage and lot operators, not from maps.
Plan
Seed from BMC data + named OSM parkings, verify, store in Firestore; later add operators and an admin screen for live counts.

Dev login uses a real test account, not Anonymous sign-in

3 Nov 2026

The debug-only Dev login button signs in with a test user whose email and password live in local.properties. Anonymous sign-in stays off in Firebase.

Why
The Firebase API key ships inside the APK. With Anonymous on, anyone could create signed-in users from a script and reach any data whose rules only check request.auth != null.
How
Add a user in Firebase → Authentication → Users, then set DEV_LOGIN_EMAIL and DEV_LOGIN_PASSWORD in local.properties and rebuild.
Release
The button is hidden when BuildConfig.DEBUG is false, and release builds get empty credential fields.

Personal repo pushes go through github-personal

Oct 2026

ParkOver commits and pushes use the github-personal SSH alias (Dhruvk2004), never the work key.

How
The repo sets core.sshCommand "ssh -o IdentitiesOnly=yes" so the work key isn't offered first.

Secrets stay in local.properties

Oct 2026

The Maps key (MAPS_API_KEY) and dev login credentials are read from the git-ignored local.properties at build time. Nothing secret goes in strings.xml or the repo.
